================
--- Purpose ---
================
Manages credential file (.cip) for user authentication.
Supports multiple users in one credential file with role-based access (admin/user).
Validates usernames (>= 3 chars, letters/digits/hyphen/underscore) and passwords
(min 5 chars, must include uppercase and lowercase letters).
Stores credentials ciphered using the default cipher key.

==============
--- Cases ---
==============
1. No credential file found -> prompt user to create username/password (becomes admin), then exit
2. Credential file found -> prompt for username/password, verify before allowing login
3. Username not found during authenticate -> offer to create new account inline
4. User exists with no password -> prompt to create password on first login
5. Command-line option to change password -> enter new password twice, overwrite file
6. Web authentication via webAuth() -> validate username/password without terminal prompts
7. Admin promotes another user to admin via promoteToAdmin()
8. List all users and their roles via getAllUsers()

===============
--- Testing ---
===============
Unit Tests:
  - isValidUsername: accepts alphanumeric/hyphen/underscore strings >= 3 chars; rejects empty, too short, special chars
  - isValidPassword: accepts strings >= 5 chars with uppercase + lowercase; rejects short or missing case
  - encrypt/decrypt: round-trip correctness, null handling
  - credentialFileExists: returns true/false based on file presence
  - isCredentialsEmpty: empty file returns true, populated file returns false
  - isAdminUser: returns true for admin role, false otherwise
  - promoteToAdmin: promotes regular user, rejects already-admin/non-existent
  - getAllUsers: returns correct user/role pairs
  - webAuth: correct password returns true, wrong returns false

Integration Tests:
  - Create credentials -> authenticate with same credentials succeeds
  - Authenticate with wrong password -> fails
  - Authenticate with unknown username -> offer to create account
  - Change password -> old password fails, new password succeeds
