TopSecret
04/10/2026

================
--- Purpose ---
================
Main entry point for the application. Handles startup logic including
credential initialization, authentication, and launching either the
terminal UI or web server based on command-line arguments.

=======================
--- Implementation ---
=======================

TopSecret
----------------------------
-CREDENTIAL_FILE: String = "credentials.cip"
-KEY_PATH: String = "ciphers/key.txt"
-db: DatabaseManager
----------------------------
+main(args: String[]): void

=================
--- Behavior ---
=================
1. Create a Password instance with the cipher key
2. If no credential file exists or it is empty:
   - Prompt the user to create first account (becomes admin)
   - Record account creation in audit log
3. Check for "-w" flag in args:
   - If present: launch WebController on port 3002
   - If absent: launch UserInterface (terminal mode)
4. Terminal mode supports additional args:
   - "-p": change password
   - "-u <username>": create a new user

===============
--- Testing ---
===============
Note: TopSecret.main() is the application entry point and is tested
indirectly through UserInterface and WebController tests.
Direct testing requires mocking System.in and is not prioritized.
