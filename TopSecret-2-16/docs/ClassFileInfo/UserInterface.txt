UserInterface
04/10/2026

================
--- Purpose ---
================
Terminal-based interactive UI controller. Authenticates the user via Password,
then provides a menu-driven interface for browsing missions, agents, facilities,
messages, and (for admins) the audit log.

==============
--- Menus ---
==============
Main Menu:
  B - Mission Briefs
  A - Agents
  F - Facilities
  G - Messages
  E - Edit Facility
  P - Promote User to Admin (admin only)
  R - Review Audit Log (admin only)
  X - Exit

Missions Submenu: L (list), S (search), # (read), N (new), M (back)
Agents Submenu:   L (list), # (detail), N (new), M (back)
Facilities Submenu: L (list), # (detail), N (new), E (edit), M (back)
Messages Submenu: S (send), V (view inbox), M (back)

Command-line args processed in run(args):
  -p  : change password
  -u <username> : create a new user
